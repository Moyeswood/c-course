# 附课：git 与 GitHub 入门

> 目标：会用 git 保存你的每一次进步，会把代码传到 GitHub，理解"版本控制"是什么。
> 本课不需要一次全记住——先跟着走一遍流程，以后每次写代码都重复这几条命令，两周就成肌肉记忆。

---

## 1. 为什么需要 git

你写代码的过程大概是：`程序.c` → 改坏了 → 保存 → 想退回却找不回 → `程序备份.c` → `程序备份2.c` → `程序最终版.c` → `程序最终版2.c`……😵

git 是**时间机器**：每次你觉得"这一步不错"，就打个"存档点"（叫 commit）。之后：
- 随时回到任意存档点
- 查看每次改了什么
- 把代码传到 GitHub 云端，换电脑也能接着写

## 2. 三个区域（最重要的概念）

```
  工作区          暂存区            仓库
  (你写的文件)  →  (购物车)    →   (存档点历史)
     │               │                │
     │  git add      │   git commit   │
     │ ────────────> │ ─────────────> │
     └── 修改文件 ─────────────────────┘
```

- **工作区**：你正在编辑的文件
- **暂存区**：`git add` 把改动放进"购物车"——决定这次存档包含哪些文件
- **仓库**：`git commit` 结账，生成一个永久存档点

为什么要分两步？因为你可以挑着存：改了两个文件，只想存其中一个，就先 `git add 那个文件` 再 commit。

## 3. 日常五连（你每天要用的就这些）

```bash
git status                  # 看: 哪些文件改了/没存/没提交
git add 文件名              # 放进购物车 (git add . 是全部)
git commit -m "描述这次改了什么"   # 存档! 描述要写清楚
git push                    # 推到 GitHub 云端
git log --oneline           # 看存档历史
```

**commit 信息怎么写**：像给未来的自己留言。好例子：`"第1课练习: 完成三圆练习"`；坏例子：`"改"`、`"update"`。

## 4. 常用自救命令

```bash
git diff                    # 看具体改了哪几行 (还没 add 的)
git checkout -- 文件名      # 撤销工作区改动, 回到上次存档
git reset --soft HEAD~1     # 撤销最近一次 commit (改动还在)
```

> ⚠️ 危险命令 `git reset --hard`、`git push -f` 先别碰，用之前问我。

## 5. 连接 GitHub

你的代码已经在本地建好仓库了（`c-course` 目录）。GitHub 是**远程仓库**——把存档历史同步到云端。

**第 1 步：登录**（只做一次，交互式命令，在终端直接跑）：

```bash
gh auth login
```

按提示选：`GitHub.com` → `HTTPS` → 问你要不要用 git 凭据时选 **Yes** → `Login with a web browser` → 复制终端显示的 8 位验证码 → 浏览器里粘贴授权。

**第 2 步：创建远程仓库并推送**（只做一次）：

```bash
gh repo create c-course --public --source=. --remote=origin --push
```

这一条命令做了 4 件事：在 GitHub 上建仓库 → 关联本地 → 命名为 origin → 把全部存档推上去。

**第 3 步：以后每次的节奏**：

```bash
写代码 → git add . → git commit -m "..." → git push
```

**换电脑/重装系统后**，把云端代码拿回来：

```bash
gh repo clone 你的用户名/c-course
```

## 6. 本课练习

1. 登录 GitHub（`gh auth login`）
2. 创建远程仓库并推送（上面的命令）
3. 打开 GitHub 网页版，找到你的仓库，点开 `lesson00` 里的 `hello.c` 看看——你的代码上云端了！
4. 修改任意文件（比如在 README.md 末尾加一行"我在学 git"），练习完整流程：`add` → `commit` → `push`，然后刷新网页确认改动上去了
5. 试着 `git log --oneline` 看你的存档历史

## 命令速查卡（贴墙上）

| 想做什么 | 命令 |
|---|---|
| 看当前状态 | `git status` |
| 存档 | `git add . && git commit -m "说明"` |
| 传云端 | `git push` |
| 看历史 | `git log --oneline` |
| 看改了啥 | `git diff` |
| 撤销未存档的改动 | `git checkout -- 文件` |

> 以后每完成一课的练习，就 commit + push 一次——你的 GitHub 仓库会变成你成长的完整记录，毕业时这就是你的第一份"作品集"。
