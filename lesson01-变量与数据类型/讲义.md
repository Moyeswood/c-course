# 第 1 课：变量与数据类型

> 目标：学会"用变量记住数据"，理解 C 的基本数据类型，让图形听变量的指挥。

---

## 1. 变量：给数据起个名字

上一课我们画的圆，位置、大小、颜色都是**写死**的。如果想改半径，要改代码重新编译。变量就是用来**记住会变的值**：

```c
int r = 80;                    /* 声明一个整数变量 r, 初始值 80 */
solidcircle(200, 150, r);      /* 半径用变量, 改 r 的值图形就跟着变 */
```

**变量三要素**：

| 要素 | 例子 | 说明 |
|---|---|---|
| 类型 | `int` | 决定能存什么、占多大 |
| 名字 | `r` | 你起的名字，规则见第 4 节 |
| 值 | `80` | 当前记住的数据，可改变 |

```c
int r;          /* 声明 (不初始化, 值是垃圾, 别用!) */
r = 80;         /* 赋值 */
r = 100;        /* 再赋值, 旧值被覆盖 */
int x = 10;     /* 声明 + 初始化, 一步到位 (推荐) */
```

## 2. 基本数据类型

```c
int     age = 20;         /* 整数: 约 ±21 亿 (4 字节) */
float   pi  = 3.14f;      /* 单精度小数 (4 字节), 注意 f 后缀 */
double  e   = 2.71828;    /* 双精度小数 (8 字节), 精度更高, 推荐 */
char    ch  = 'A';        /* 单个字符 (1 字节), 用单引号 */
```

小数的默认类型是 `double`。`3.14` 直接赋给 float 变量会警告，所以要写 `3.14f`。

`sizeof(类型)` 可以查看占多少字节：

```c
printf("%zu\n", sizeof(int));    /* 打印 4 */
```

## 3. 类型转换

```c
int a = 5;
double b = 2.0;
printf("%f\n", a / b);    /* 2.5: int 和 double 运算, 自动转成 double */
printf("%d\n", 5 / 2);    /* 2  !!! 整数除以整数得整数, 小数被丢掉 */
printf("%d\n", (int)3.99); /* 3: 强制转换, 直接截断不是四舍五入 */
```

**新手第一大坑**：`5 / 2` 是 2 不是 2.5！想要小数，至少一个操作数是小数：`5.0 / 2`。

## 4. 命名规范

```c
int playerScore;      /* ✓ 多个单词: 驼峰 (或下划线 player_score) */
int x1, x2;           /* ✓ 可以带数字, 但不能以数字开头 */
int 2x;               /* ✗ 非法! 不能数字开头 */
int class;            /* ✗ 关键字不能用作变量名 (class/if/for/...) */
```

- 名字要有意义：`r` 不如 `radius` 清晰，`a` 不如 `age` 清晰
- C 是大小写敏感的：`Score` 和 `score` 是两个不同变量

## 5. 图形实战：让变量指挥图形

打开 `colors.c`，体会"改一处值、图形跟着变"：

```c
int cx = 200, cy = 150;      /* 圆心坐标 */
int radius = 80;             /* 半径 */
int ring = 5;                /* 圆的数量 */
int gap = 15;                /* 每个圆缩小的量 */

for (int i = 0; i < ring; i++) {                    /* 循环画 5 个圆 (下下课的正式内容) */
    solidcircle(cx, cy, radius - i * gap);          /* 半径逐个减小 */
}
```

试着把 `ring` 改成 3、`gap` 改成 30，观察变化——**这就是变量的意义**。
