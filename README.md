# C 语言学习路线（从零开始 · 图形版）

> 学习方法：**每课三步** —— ① 读讲义 → ② 完成练习（遇到问题随时来问我）→ ③ 把练习代码发我检查，通过后进入下一课。
> 建议节奏：每天 1 课，指针那两课可以放慢到 2~3 天。**不要跳课**，每课的练习一定要动手写，抄代码学不会编程。

---

## 阶段一：基础语法（第 0~6 课）

| 课 | 主题 | 知识点 | 图形练习（用你的 EasyX！） |
|---|---|---|---|
| 0 | 环境与第一个程序 | gcc 是什么、编译的四个阶段、`main` 函数、`printf` | 窗口弹出 + 画第一个圆 |
| 1 | 变量与数据类型 | 变量三要素、`int/float/double/char`、`sizeof`、命名规范、类型转换 | 用变量控制图形的位置、大小、颜色 |
| 2 | 输入与格式化输出 | `scanf` 的坑（`&`、缓冲）、`printf` 格式说明符、转义字符 | 输入半径画圆、输入坐标画图 |
| 3 | 运算符与表达式 | 算术/关系/逻辑/位运算、优先级、自增自减、复合赋值 | 几何计算（面积/距离）+ 颜色位运算 |
| 4 | 分支结构 | `if/else if/else`、`switch`、三元运算符、嵌套分支 | 键盘控制小球移动（判断按键）、菜单交互 |
| 5 | 循环结构 | `for/while/do-while`、`break/continue`、嵌套循环 | 循环画网格/星空/渐变色带/同心圆 |
| 6 | 数组 | 一维/二维数组、遍历、冒泡排序、线性查找 | 排序过程可视化、生命游戏数据模型 |

## 阶段二：函数与指针（第 7~9 课，C 的核心）

| 课 | 主题 | 知识点 | 图形练习 |
|---|---|---|---|
| 7 | 函数 | 定义/调用/参数/返回值、作用域、递归 | 把"画房子/画树"封装成函数；递归画分形树 |
| 8 | 指针基础 | 地址与 `&`、指针与 `*`、指针运算、指针与数组 | 用指针遍历像素数组 `GetImageBuffer`，实现反色/渐变 |
| 9 | 指针进阶 | 指针与函数（传址调用）、指针数组、`const` 指针 | 交换函数、像素滤波（模糊/锐化） |

## 阶段三：数据组织（第 10~13 课）

| 课 | 主题 | 知识点 | 图形练习 |
|---|---|---|---|
| 10 | 字符串 | 字符数组、`'\0'`、`string.h` 常用函数、字符串遍历 | 打字游戏、滚动字幕、字符串动画 |
| 11 | 结构体 | `struct`、`typedef`、结构体数组、结构体指针 | 粒子系统（每个粒子是一个结构体） |

## 编译命令速查

```bash
# 纯终端程序（不需要图形）
gcc 程序.c -o 程序 && ./程序

# 纯 C + EasyX 图形程序（本课程统一用这个）
g++ -x c 程序.c -x none $(pkg-config --libs easyx) -o 程序 && ./程序
```

> **更简单**：每个课程目录和课程根目录都有 Makefile，直接 `make` 即可（`make 文件名` 编译单个，`make clean` 清理）。
> `-x c` 告诉编译器"按纯 C 编译"（不是 C++），图形库已全局安装好。

## 给你的三条建议

1. **错误是最好的老师**——编译器报错别慌，把报错信息完整发我，学会读报错是编程第一技能
2. **每个练习先自己想 10 分钟**再问我，我会给提示而不是直接给答案
3. **学完一课就写个小玩具**——哪怕是"会跳的球"，都比任何作业都值得
