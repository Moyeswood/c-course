# C 语言学习之旅（c-course）

> 从零开始学 C 语言，用 **EasyX 图形库**让每一课都有看得见的反馈——不再面对黑乎乎的终端。

## 项目简介

这是一个**逐课模式的 C 语言自学工程**：每课一份讲义 + 5 个练习，知识点与图形编程配对。学分支就做"键盘控制小球"，学数组就做"排序可视化"，学指针就直接操作屏幕像素做滤镜。配合 [Claude Code](https://claude.com/claude-code) 一对一辅导：读讲义 → 做练习 → 发代码检查 → 进入下一课。

配套学习笔记仓库：[Moyeswood/notes](https://github.com/Moyeswood/notes)

## 学习路线（15 课 + 项目）

**阶段一：基础语法**
| 课 | 主题 | 图形练习 |
|---|---|---|
| 0 | 环境与第一个程序 | 窗口 + 第一个圆 |
| 1 | 变量与数据类型 | 变量控制图形位置/大小/颜色 |
| 2 | 输入与格式化输出 | 输入半径画圆 |
| 3 | 运算符与表达式 | 几何计算 + 颜色位运算 |
| 4 | 分支结构 | 键盘控制小球、菜单交互 |
| 5 | 循环结构 | 网格/星空/渐变/同心圆 |
| 6 | 数组 | 排序可视化、生命游戏模型 |

**阶段二：C 的核心**
| 课 | 主题 | 图形练习 |
|---|---|---|
| 7 | 函数 | 封装画房子/画树，递归分形树 |
| 8 | 指针基础 | 指针遍历像素：反色/渐变 |
| 9 | 指针进阶 | 像素滤波（模糊/锐化） |

**阶段三：数据组织**
| 课 | 主题 | 图形练习 |
|---|---|---|
| 10 | 字符串 | 打字游戏、滚动字幕 |
| 11 | 结构体 | 粒子系统 |
| 12 | 动态内存 | 动态粒子增删 |
| 13 | 文件操作 | 排行榜存档、像素文件读写 |

**阶段四：综合项目**
- 14 课：贪吃蛇（完整版，含排行榜）
- 15 课：自由选题（五子棋 / 俄罗斯方块 / 打砖块 / 绘图板 / 打字游戏）

## 依赖与编译

需要 [EasyX for Linux](https://github.com/Moyeswood) 图形库（本工程配套从零移植的 EasyX Linux 版）和 SDL2：

```bash
# Arch
sudo pacman -S sdl2 sdl2_image sdl2_ttf noto-fonts-cjk
# Ubuntu/Debian
sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev fonts-noto-cjk
```

```bash
make            # 编译（每个课程目录和根目录都能用）
make 程序名      # 只编译某一个
make clean      # 清理编译产物
```

## 学习方法

1. 每课三步：读讲义 → 做练习 → 发代码给 Claude Code 检查后进下一课
2. 建议每天 1 课，指针两课放慢到 2~3 天，不跳课
3. 每完成一课 commit 一次——这个仓库就是成长记录
4. 报错是最好的老师：把完整报错信息发给 Claude，学会读报错是编程第一技能
