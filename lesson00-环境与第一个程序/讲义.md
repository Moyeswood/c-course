# 第 0 课：环境与第一个程序

> 目标：理解"编译"是什么，写出并运行人生第一个 C 程序（终端版 + 图形版各一个）。

---

## 1. 什么是 C 语言程序

你写的 C 代码（文本文件）计算机**看不懂**，需要翻译成机器指令。这个翻译工具叫**编译器**，你机器上有两个：

```bash
gcc --version      # GNU 编译器
clang --version    # LLVM 编译器
```

两个都能用，本课程用 `gcc`（也可以换成 clang，命令一样）。

## 2. 编译的四个阶段（了解即可）

```
你写的源码(.c) → 预处理 → 编译 → 汇编 → 链接 → 可执行文件
    你好.c        展开宏   翻译成汇编  转成机器码  合并库文件     ./你好
```

你只需要记住一条命令：

```bash
gcc 你好.c -o 你好     # 编译: 把"你好.c"变成可执行文件"你好"
./你好                 # 运行
```

## 3. 第一个程序：解剖 hello.c

打开同目录的 `hello.c`：

```c
#include <stdio.h>        /* ① 引入"标准输入输出"工具箱, printf 就在里面 */

int main(void)            /* ② 程序入口: 每个 C 程序都从 main 开始执行 */
{
    printf("Hello, C!\n"); /* ③ 打印一行文字, \n 是换行 */
    return 0;              /* ④ 返回 0 = "程序正常结束", 告诉操作系统 */
}
```

每个符号都有意义，现在你只需要记住**结构**：

- `#include <xxx.h>`：借用别人写好的工具（头文件）
- `int main(void) { ... }`：程序从这里开始，花括号是"身体"
- 每条语句以 `;` 结尾（中文分号 `；` 是新手第一坑！）

**编译运行**：

```bash
cd ~/Documents/claude001/c-course/lesson00-环境与第一个程序
gcc hello.c -o hello && ./hello
```

## 4. 第二个程序：图形版 Hello World

打开 `easyx_demo.c`，用你昨天装好的 EasyX：

```c
#include <graphics.h>      /* 图形库的头文件 */
#include <stdio.h>

int main(void)
{
    initgraph(400, 300);        /* 开一个 400x300 的窗口 */
    cleardevice();              /* 用背景色清屏 */
    setfillcolor(RED);          /* 设填充色为红 */
    solidcircle(200, 150, 80);  /* 在 (200,150) 画实心圆, 半径 80 */
    settextstyle(24, 0, NULL);  /* 设置文字大小 */
    outtextxy(120, 40, "我的第一个图形程序!");  /* 在 (120,40) 写字 */
    delay(3000);                /* 暂停 3 秒让你看到画面 */
    closegraph();               /* 关窗口 */
    return 0;
}
```

**编译运行**（注意：图形程序用这条命令，因为库是 C++ 实现的）：

```bash
g++ -x c easyx_demo.c -x none $(pkg-config --libs easyx) -o demo && ./demo
```

或者更简单——**每个课程目录里都有 Makefile，直接**：

```bash
make            # 编译本目录所有 .c
make hello      # 只编译 hello.c
make clean      # 删除编译产物
```

（`make` 只认**当前目录**的 Makefile——这也是你刚才在 lesson00 里报 "No makefile found" 的原因；现在每个课程目录都配了一个。）

你会看到一个窗口弹出，中间一个红圆，上面一行字——**这就是你 C 语言之旅的起点。**

## 5. 本课练习

1. **改文字**：把 `"我的第一个图形程序!"` 换成你自己的话
2. **改颜色**：把 `RED` 换成 `GREEN`、`BLUE`、`YELLOW`（EasyX 内置 16 种颜色：BLACK, BLUE, GREEN, CYAN, RED, MAGENTA, BROWN, LIGHTGRAY, DARKGRAY, LIGHTBLUE, LIGHTGREEN, LIGHTCYAN, LIGHTRED, LIGHTMAGENTA, YELLOW, WHITE）
3. **改图形**：把 `solidcircle` 换成 `solidrectangle(100, 100, 300, 200)`（实心矩形，四个数是左上角和右下角坐标）
4. **画多个**：在清屏和关闭之间，连续画 3 个不同颜色不同位置的圆（试试能不能让三个圆**排成一条斜线**？）
5. **思考题**（不用写代码）：窗口左上角坐标是多少？`(0,0)` 在哪个角？
